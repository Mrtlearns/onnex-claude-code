# Challenges

## C1: Finding PI Firm Prospects Willing to Pilot
- **Impact:** No clients = no validation = no revenue
- **Approach:** Leverage ShareCRM partnership for warm NDT-to-PI intros. Target Las Vegas market first (local proximity advantage). Identify 3–5 small PI firms (1–5 attorneys) as pilot candidates willing to trade lower price for being first.
- **Strategy ref:** S4 (ShareCRM partnership), S3 (Las Vegas first)

## C2: Pricing and Positioning vs Litify / Filevine
- **Impact:** Existing PI CRMs (Litify, Filevine, Clio) have brand recognition. "Another PI software" objection will be common.
- **Approach:** Position as AI-OS layer on top of or replacing existing tools — not a CRM. Lead with speed-to-lead ROI (first firm to call wins the case). Show tangible case acquisition improvement, not feature comparison.
- **Strategy ref:** S1 (speed-to-lead as hook)

## C3: Technical Complexity — Temporal + Twilio TCPA Compliance
- **Impact:** TCPA violations carry $500–$1500 per message fines. Must get opt-in flow right before any client touches it.
- **Approach:** Build TCPA compliance layer as a first-class service (not an afterthought). Temporal handles workflow state and retry logic. Twilio handles consent tracking via opt-in keywords and DNC list integration.
- **Strategy ref:** S2 (shared infra — compliance built once, reused across clients)
