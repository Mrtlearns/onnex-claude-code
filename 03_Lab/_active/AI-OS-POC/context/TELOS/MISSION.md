# Mission

## M0: Primary Mission
Build financial freedom through technology ownership — deliver AI-powered operating systems to SME clients that replace fragmented tools with unified, intelligent platforms.

## M1: Agency AI-OS POC Mission
Prove the full Agency AI-OS platform end-to-end in a single monorepo POC. Every module (CRM, projects, deals, invoices, time tracking, documents, AI assistant, workflow automation) must be functional, multi-tenant, and demo-ready. This POC is the master template for all Onnex vertical OS deployments.

## M2: Production Readiness
Evolve the POC from "feature-complete" to "client-deployable" — hardened auth, TLS, formal test coverage, CI/CD, and a clean demo environment that can be spun up on demand.
