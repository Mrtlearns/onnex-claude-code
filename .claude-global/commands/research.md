# /research

Conduct tiered web research on a topic. Choose depth based on need.

## Modes

| Mode | Use When |
|------|---------|
| **Quick** | Fast orientation, 2-3 sources, key facts only |
| **Standard** | Balanced research, 5-8 sources, structured findings |
| **Extensive** | Deep dive, 10+ sources, full report with recommendations |

## Instructions

1. Ask for the research topic and preferred mode if not specified
2. Default to **Standard** if no mode given
3. Search systematically — don't stop at first result
4. Synthesize findings, don't just list links
5. End with: Key Findings, Gaps/Unknowns, Recommended Next Steps

## Domain-Specific Notes

**SAP:** Check SAP Help Portal, SAP Community, SAP Notes first.
**Cybersecurity:** Cross-reference NVD, OWASP, vendor advisories.
**Legal (PI):** Check jurisdiction-specific rules — TCPA varies by state.
**AI Tooling:** Check official docs + recent GitHub issues for accuracy.
