QUICK API REFERENCE
================================================================================

ENDPOINTS (run on FastAPI backend):

  POST /api/upload
    Upload: Single .msg file
    Returns: { success, email {...}, attachments [...] }
    
  POST /api/batch
    Upload: Multiple .msg files
    Returns: { batch: [...], summary: {...} }
    
  GET /api/download/{folder}/{filename}
    Download: Extracted attachment file
    
  GET /api/health
    Status: Check backend health
    
  GET /docs
    Swagger UI: Interactive API explorer

REACT COMPONENT:

  <MSGExtractor 
    apiUrl="http://localhost:8000"      // Backend URL
    onExtract={(result) => {...}}       // Callback when done
  />

================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: "Cannot POST /api/upload"
  ✓ Is FastAPI server running? python3 msg_api_server.py
  ✓ Is it on correct port? Check terminal output
  ✓ Is apiUrl correct? <MSGExtractor apiUrl="http://localhost:8000" />

ISSUE: "CORS error in browser console"
  ✓ FastAPI allows localhost:3000 by default
  ✓ If different port, edit msg_api_server.py line 30
  ✓ Add your domain to allow_origins

ISSUE: File upload fails silently
  ✓ Check browser console (F12) for errors
  ✓ Check backend terminal for server errors
  ✓ Verify file is .msg format (not .eml, .pst, etc.)

ISSUE: Attachments don't download
  ✓ Check browser console for download URL errors
  ✓ Check /tmp/msg_extractions/ exists with extracted files
  ✓ Verify folder/filename path is correct

See INTEGRATION_GUIDE.md for more troubleshooting.
