STEP 1: Start Backend (1 min)
  $ python3 msg_api_server.py
  → Server runs on http://localhost:8000
  → Leave this terminal open

STEP 2: Add Component to Next.js (2 min)
  
  a) Copy files:
     cp MSGExtractor.tsx → your-app/app/components/
     cp MSGExtractor.module.css → your-app/app/components/
  
  b) Create page: app/msg-extractor/page.tsx
     
     'use client'
     import MSGExtractor from '@/components/MSGExtractor'
     
     export default function Page() {
       return (
         <main style={{ padding: '2rem' }}>
           <h1>📧 Email Extractor</h1>
           <MSGExtractor apiUrl="http://localhost:8000" />
         </main>
       )
     }

STEP 3: Test (2 min)
  → Go to: http://localhost:3000/msg-extractor
  → Drop a .msg file
  → See email + attachments
  → Download attachment files

LOCAL:
  Backend:  python3 msg_api_server.py → localhost:8000
  Frontend: npm run dev → localhost:3000
  URL in component: apiUrl="http://localhost:8000"

PROXMOX VMs:
  Backend VM:  192.168.x.x:8000 (run msg_api_server.py)
  Frontend VM: 192.168.x.y:3000 (Next.js)
  URL in component: apiUrl="http://192.168.x.x:8000"

PRODUCTION:
  Use reverse proxy (Nginx) or API Gateway
  Backend hidden behind /api proxy path
  URL in component: apiUrl="/api"

Component Props:
  apiUrl: string                    Backend URL (default: localhost:8000)
  onExtract: (result) => void       Called when extraction completes

Result Object:
  success: boolean                  True if extraction succeeded
  email.from: string                Sender email address
  email.to: string                  Recipient email address
  email.subject: string             Email subject line
  email.date: string                ISO datetime
  email.body: string                Full email body text
  attachments: Array                List of attachment objects
  attachmentCount: number           Number of attachments

Browser Events:
  Drag-drop: Automatically detected
  File click: Click anywhere in drop zone
  Download: Built-in download buttons per attachment

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Cannot POST /api/upload"
  → Is FastAPI running? python3 msg_api_server.py
  → Check apiUrl matches server address
  
"CORS error in console"
  → Edit msg_api_server.py line 30, add your domain
  
"File upload fails silently"
  → Press F12, check browser console for error
  → Check backend terminal for server errors
  
"Attachments won't download"
  → Check /tmp/msg_extractions/ has extracted files
  → Verify download URL in browser network tab
