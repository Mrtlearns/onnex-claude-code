# Beliefs

## B1: Two-stage beats one-stage for RT analysis
Generic prompting of raw RT documents produces unreliable results. Classifying the part type first and assembling code-specific prompts dynamically produces consistently better findings.

## B2: ITAR compliance is a competitive moat, not a constraint
Building it correctly from day one means we can serve the entire NDT/aerospace market. Cutting corners means we can only serve the non-regulated segment.

## B3: Engineers should review findings, not generate them
The highest-value use of an NDT engineer's time is judgment and sign-off — not document processing. AI handles the processing; the engineer handles the professional certification.

## B4: Local LLM inference is a real differentiator
Dual RTX 3090 + Ollama means we can offer air-gapped deployment and dramatically lower per-job cost at scale. This matters for large-volume NDT clients.
