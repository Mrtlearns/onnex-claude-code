CODE-SPECIFIC MODULE: Storage Tank Radiographic Inspection

GOVERNING STANDARDS:
  API 650: Welded Tanks for Oil Storage — primary standard for atmospheric storage tanks
  API 620: Design and Construction of Large, Welded, Low-Pressure Storage Tanks
  API 653: Tank Inspection, Repair, Alteration, and Reconstruction (in-service)
  AWS D1.1: Structural welding for ladder/stairway/platform attachments

KEY INSPECTION AREAS:
  1. Shell course butt welds (vertical seams — Category A equivalent):
     - All vertical seams: 100% RT if shop-fabricated; spot RT if field-erected
     - API 650 Section 8.1: RT requirements by tank volume, service, and design
  2. Shell course to shell course horizontal seams (circumferential — Category B equivalent):
     - Spot RT at intersections with vertical seams
     - Full RT for tanks in PWHT service or H2S service
  3. Bottom plate welds:
     - Annular plate butt welds: 100% RT of radial seams per API 650 Section 7
     - Sketch plate lap welds: generally VT only; note in findings
  4. Roof welds:
     - Cone roof: RT not typically required; specify VT
     - Dome/geodesic: per designer specification
  5. Nozzle welds:
     - Shell nozzles: RT per API 650 Section 8.1 nozzle requirements
     - Bottom sump/drain: RT if full-pen weld specified

SEVERITY MAPPING:
  CRITICAL: Shell-to-bottom annular plate weld (highest stress point, catastrophic failure risk if defective), nozzle attachment welds at high-liquid-level zones
  HIGH:     Vertical shell seams in lower courses (highest hydrostatic pressure), annular plate radial butt welds
  MEDIUM:   Vertical shell seams in upper courses, horizontal shell seams (intersections with vertical seams)
  LOW:      Roof structure welds, ladder/platform attachment welds, non-pressure-boundary attachments

GEOMETRY NOTES:
  - Shell courses: CylinderGeometry(tankOD/2, tankOD/2, courseHeight, 128) — one per course
  - Bottom plate: CylinderGeometry(tankOD/2, tankOD/2, plateThk, 128) — very flat disk
  - Annular plate ring: TorusGeometry(tankOD/2, annularWidth/2, 8, 128) at bottom edge
  - Cone roof: ConeGeometry(tankOD/2, roofHeight, 64)
  - Dome roof: SphereGeometry(roofRadius, 64, 32, 0, 2*PI, 0, PI/3) — partial sphere
  - Roof nozzles/vents: CylinderGeometry at roof surface
  - Shell nozzles: CylinderGeometry positioned on shell at appropriate elevation

FIELD CONSTRUCTION NOTES:
  - Most large tanks are field-erected; RT is performed in field conditions
  - Weather protection required for field RT (wind, moisture affect film quality)
  - Gamma-ray sources (Ir-192 most common) preferred for field work over X-ray machines
  - Exclusion zone requirements for gamma sources on active tank farms
