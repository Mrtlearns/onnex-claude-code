CODE-SPECIFIC MODULE: Generic RT Analysis (Fallback)

This module is used when the part type does not match a specific code module, or as a
universal fallback. Apply general RT best practices across all discontinuity types.

GENERAL RT PRINCIPLES:
  1. Identify all welded joints, cast sections, or forged features that could contain volumetric discontinuities
  2. Classify zones by structural criticality (load-bearing vs. non-structural)
  3. Apply general film technique per ASME Section V Article 2 as baseline
  4. Flag any areas requiring specialized technique (CT, panoramic, crawler)

UNIVERSAL DISCONTINUITY TYPES:
  - Porosity (gas): spherical voids from entrapped gas during solidification or welding
  - Slag/inclusion: non-metallic material trapped in weld or casting
  - Lack of fusion (LOF): weld not fused to base metal at one or both faces
  - Incomplete penetration (IP): root of weld joint not fully filled
  - Crack: linear planar discontinuity — always rejectable under any code
  - Undercut: groove at weld toe reducing base metal section
  - Overlap: weld metal flowing over base metal without fusion

SEVERITY MAPPING (generic):
  CRITICAL: Any visible crack indication, weld intersections, primary load path welds
  HIGH:     Full-penetration structural welds, pressure-boundary welds, welds at section transitions
  MEDIUM:   Secondary welds, partial-penetration joints, attachment welds
  LOW:      Non-structural attachments, cosmetic welds, non-pressure items

GEOMETRY NOTES:
  - Default to CylinderGeometry for round/tubular shapes
  - Default to BoxGeometry for prismatic/plate shapes
  - Use LatheGeometry for rotationally symmetric profiles that don't fit standard primitives
  - Provide bounding box dimensions regardless of primitive type chosen

TECHNIQUE DEFAULTS:
  - Source: Ir-192 for material thickness 0.5"–3"; X-ray for <0.5"; Co-60 for >3"
  - SFD: minimum 12" for Ir-192; adjust per geometric unsharpness formula
  - IQI: wire type per ASTM E747, 2% sensitivity minimum
  - Film: ASTM E1815 Class 1 or equivalent; density 2.0–3.5
  - Technique: SWSI for accessible welds; DWDI for small bore pipe or inaccessible backwall

NOTE: For final deliverable, the client should specify the applicable code so a code-specific
analysis can replace this generic assessment.
